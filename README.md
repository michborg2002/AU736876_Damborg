# Colonial Legacy and GDP Analysis
This project investigates whether GDP per capita can be used as a tool for studying the long-term legacy of European colonialism. Using the Gapminder dataset and visualizations produced in R, the project compares GDP development across selected former colonies and non-colonized countries between 1952 and 2007.
